# 回款抵账规则

银行回款按客户匹配到已签滞港费账单。金额一律以整数分保存，页面与接口同时接受元。

## 抵扣顺序

1. **指定用途**：付款人指定某张账单时，指定金额先抵该账单。
   - 该账单有争议、未签、不存在或属于其他客户时，这笔钱进入**待认领**，不会挪去抵同一客户的其他欠款，即使其他欠款已逾期。
   - 指定金额超过该账单未结余额时，超出部分视为未指定用途，回到第 2 步。
2. **未指定用途**：按到期日从早到晚，依次抵同一客户的**已签且无争议**账单；同日按账单号排序。
3. 仍无法落账的金额留在**待认领**。

争议解除后，可在“待认领处理”把该笔款认领到账单；认领同样要求账单已签、无争议、属于同一客户，且不超过待认领额与未结余额。

## 冲回

- 冲回一笔回款只撤销**这笔回款自己**的抵扣与待认领，它抵掉的欠款恢复为未结。
- 其他回款的抵扣记录保持原样，后来到账的钱仍按原账单生效，不会因为冲回而重新分配。
- 每笔回款保留原抵扣明细以备审计，冲回后状态为 `REVERSED`，不再计入实收。
- 已冲回的回款不能重复冲回，也不能再认领。

## 重跑与幂等

- 带 `receipt_id` 或 `bank_ref` 的回款按其编号识别；两者都没有时按内容（客户、金额、指定用途、流水号）识别。
- 同一笔回款重复提交返回原记录并标记 `replayed=true`，不会重复销账。
- 编号相同但内容不同返回 `RECEIPT_CONFLICT`，需人工核对。

## 对账恒等式

```
每笔未冲回回款：已抵 + 待认领 = 回款金额
全部未冲回回款：已抵合计 + 待认领合计 = 未冲回实收合计
```

工作台“回款抵扣”面板实时显示这两个恒等式，并校验账单已抵不超过账单金额、回款只抵同一客户账单。
